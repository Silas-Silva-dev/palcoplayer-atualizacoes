# Palco Player: canal de atualizações

Versões publicadas do [Palco Player](https://palcoplayer.com.br): só os instaladores (Windows e Mac), o manifesto
`atualizacao.json` e a assinatura dele, `atualizacao.sig`. Nenhum código fica aqui.

O Palco Player instalado procura versões novas por este canal (Ajustes › Sobre) e só aceita manifesto com a
assinatura do Palco Player, versão mais nova que a instalada e arquivo cujo tamanho e resumo (SHA-512) batem com o
manifesto.

Para comprar, baixar e ativar: [palcoplayer.com.br](https://palcoplayer.com.br) · contato: contato@palcoplayer.com.br
